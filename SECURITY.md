# Security

Report a vulnerability privately through GitHub: [Report a vulnerability](https://github.com/loopledger/loopledger/security/advisories/new). Don't open a public issue.

In scope: the ledger's signature verification and evidence hashing (`packages/ledger`), the adapters, and any schema rule whose absence would let a forged or unsigned event validate.

You'll get an acknowledgement within 7 days. LoopLedger is pre-release (Phase 0), so fixes land on `main` and there are no supported release branches yet.
